# 领域边界

管理元青花文物图像、授权、设计版本与邮票发行物料的关系。

现有领域资料围绕以下边界组织：

- 文物与机构档案
- 图像和文字授权
- 设计稿审批
- 发行批次追踪
- 更正与暂停
- 库存与回执
- 冲突复核
- 公开信息裁剪

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 规则要点

- 使用关系冻结：批次完成后，物料与设计、文物的对应关系不得更改；已完成批次保留当时依据，后续许可变化不回溯。
- 暂停：图像更正、授权到期、批次异常分别在设计、授权、印制环节暂停后续发行；未解除的暂停必须落实为对应批次的状态。
- 库存守恒：回执按编号入账，同一回执重复提交不得重复扣减库存，回执总量不得超过批次数量。
- 冲突复核：纹饰说明不一致、同一文物同一物料类型出现多个已批准设计等冲突必须进入复核队列。
- 公开裁剪：公众视图只包含公开文物的白名单字段，不暴露未公开库藏信息。
- 追溯：任一发行物料都可以还原其设计版本、每次批准变化、文物证据、收藏机构、图像许可与批次依据。
