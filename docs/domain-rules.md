# 领域边界

管理元青花文物图像、授权、设计版本与邮票发行物料的关系。

现有领域资料围绕以下边界组织：

- 文物与机构档案
- 图像和文字授权
- 设计稿审批
- 发行物料冻结与批次追踪
- 更正、暂停与复核

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 角色与可见范围

| 角色 | actor 前缀 | 能力边界 |
| --- | --- | --- |
| 集邮项目负责人 | `manager` | 登记机构、授权、审批、冻结、解除暂停与复核结论 |
| 文博机构管理员 | `museum:<机构id>` | 只能核对本馆文物、图像与授权，可见本馆内部备注 |
| 设计团队 | `designer` | 只能使用已批准、授权有效且未暂停的内容创稿/修订 |
| 印制厂商 | `printer` | 上报完成、回执与批次异常 |
| 公众查询 | `public` | 只看公开说明，看不到内部库藏信息、授权凭证与暂停细节 |

## 核心规则

1. **只增事件流**：档案只追加事件，序号连续，每条带 SHA-256 摘要；当前状态由回放得出，历史事件不可修改，加载时校验序号与摘要。
2. **证据冻结防版本错位**：物料（五枚邮票、小型张、首日封、宣传册）冻结时记录文物版本、图像版本、授权有效期、设计修订号和完整批准链摘要。冻结一次性完成，之后不可更改。
3. **更正只追加新版本**：文物资料更正必须基于期望版本号（乐观并发），图像更正追加新版本并指向旧版；更正打开暂停点，后续发行停在审批/冻结环节，重新修订并批准后才解除。
4. **已完成批次保留当时依据**：设计修订后旧物料冻结即过时，新印批次必须以 `reissue_of` 换版并重新冻结；旧批次、旧首日封仍按冻结时的证据可追溯、可收货。
5. **授权到期暂停、续期解除**：授权到期登记 `license.expired` 并打开暂停；续期后自动关闭对应暂停。批准、冻结、开印均校验授权在"当前业务日期"有效。
6. **批次异常定点暂停**：异常只暂停该批次及其同物料后续发行，不波及其它物料；调查结论以 `hold.resolved` 记录。
7. **库存守恒与回执幂等**：同一批次下相同回执号重复提交只记 `batch.receipt_duplicate`，不重复扣减；回执总量不得超过批次数量。
8. **冲突必须复核**：冲突资料不覆盖既有事实，进入复核队列并暂停相关文物的发行；负责人给出结论后才解除。
9. **按一枚邮票可追溯**：`trace_stamp` 还原文物来源、纹饰、图像与授权版本、每次批准（含驳回）及其证据版本、冻结快照、换版链和全部批次。
