# 元青花文物邮票授权与版本档案

管理元青花文物图像、授权、设计版本与邮票发行物料的关系。

## 参与方与事实

主要参与方包括集邮项目负责人、文博机构管理员、设计人员、印制厂商、复核人员、公众查询人员。领域资料记录以下已经确认的事实：

- 邮政发行元青花主题特种邮票一套五枚和小型张
- 题材来自五家文博机构的六件元青花器物
- 首日封采用与邮票对应的文物图像和起凸工艺
- 发行档案记录每件器物的收藏机构、出土或传世来源、图像许可、纹饰说明、设计稿审批、印制工艺和发行物料
- 同一文物在邮票、小型张、首日封和宣传册中的使用关系在批次完成后冻结
- 图像更正、授权到期或印刷批次异常时后续发行暂停在对应环节，已完成批次保留当时依据
- 相同批次回执按编号入账，不得重复扣减库存
- 冲突资料必须进入复核队列
- 公众查询只能看到公开说明，不暴露未公开库藏信息

## 业务约束

- 文物来源
- 图像授权
- 发行物料版本
- 公开信息裁剪
- 批次库存守恒
- 暂停与恢复
- 冲突复核
- 单枚邮票追溯

## 资料结构

- `contracts/context.schema.json` 描述领域上下文结构，`fixtures/context.json` 提供示例
- `contracts/archive.schema.json` 描述发行档案结构，`fixtures/archive.json` 提供不含真实身份信息的示例档案
- `src/stamp_context.py` 读取并校验领域上下文
- `src/archive.py` 读取发行档案、校验业务规则，并提供公开视图裁剪、库存扣减与单枚物料追溯

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
